Cline Pass 钉住

给每个模型指定 Cline 网关背后的上游渠道。普通使用保持“自动”即可。

模型 模式 上游渠道（按顺序） 能力过滤 has 排除 排序

渠道列表从哪来？

先探测渠道。最直接的是命令行（不需要给 agent 配 MCP）：

node scripts\magpie-tool.mjs magpie_probe model=deepseek-v4.1-flash-1017 has=vision,implicit-caching

让 agent 调用时是 magpie_probe（从 GitHub 安装时是 magpie-cline-pass_probe）。

探测和校验结果写在插件状态里；这个页面只编辑钉住规则。保存后如果没生效，到 插件 → 已安装 把本插件关掉再打开。

strict：每个渠道单独试，不换渠道。 preferred：按顺序试，首个 token 前失败就换下一个。 排除 会编译成 allow-list。 能力过滤 has 是让 Cline 真正执行 only 的关键：只写上游渠道而不写 has 时，网关可能落到私有上游并忽略 only。常见值：vision, implicit-caching。 排序可选 cost / ttft / tps，留空表示不排序。
